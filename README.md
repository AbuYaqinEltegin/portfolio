# Элтегин — проекты

**Сайт:** https://eltegin.vercel.app

Личное портфолио: веб-разработка, автоматизация на Make.com, короткие видео.

- Приветствие: кыргызский орнамент («кочкор мүйүз») собирается в узор и расходится.
- Первый экран: силуэты кыргызских богатырей скачут в степь на закате.
- «Чем я занимаюсь»: три круга вращаются вокруг центра, как инь-ян.
- «Мой путь»: вкладки Калима, Көк Жол (в работе), Учёба.
- Четыре языка: русский, кыргызский, английский, арабский (справа налево).
- Учитывает `prefers-reduced-motion`.

Одна страница без сборки: всё в `index.html`, картинки в `img/`.
Ссылки для проверки: `?intro=0` — без приветствия, `?lang=ky|en|ar|ru` — язык.
Публикация: `git push` — Vercel обновляет сайт сам.
