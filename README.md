# Элтегин — проекты

**Сайт:** https://eltegin.vercel.app

Личное портфолио: сайты, автоматизация на Make.com, короткие видео.

- Приветственная анимация: кыргызский орнамент («кочкор мүйүз») собирается в узор и расходится. Учитывает `prefers-reduced-motion`, показывается один раз за сеанс (`?intro=0` — сразу сайт).
- Тёмная тема, акценты — золотой и тёмно-зелёный.
- Блок «Мой путь» с вкладками: Калима, Көк Жол (в работе), Учёба.

Одна страница без сборки: всё в `index.html`, картинки в `img/`.
Публикация: `git push` — Vercel обновляет сайт сам.
